# QForge

QForge is an AI Quality Engineering platform for testing AI-powered and agentic applications.

The initial System Under Test is an Airline Disruption and Rebooking Agent.

QForge will validate:

- Business rule compliance
- Tool selection
- Tool arguments
- API interactions
- Actual system side effects
- AI response correctness
- Hallucinations
- Regression behavior
- Reliability

The goal is to determine whether an AI system actually performed the correct action, not merely whether its response sounds correct.
